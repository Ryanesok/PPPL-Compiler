Sebelum menggunakan, pastikan model dalam format yang sesuai (.json) dan mengikuti struktur
model pada MODEL_TEMPLATE.json di dalam folder models/

Cara penggunaan:
1. Buka compilerModel.py
2. Pilih / import model yang akan di compile
3. Lakukan Compile menggunakan tombol compile.
4. Model telah selesai di compile menjadi source code.

Jika ada error, silahkan periksa Log pada console compiler.
Contoh Error:
- Gagal saat compile --> model tidak sesuai struktur yang diminta.
- test run mengalami error --> model kekurangan suatu modul/atribut pada class, tambahkan modul atau atribut pada model.
